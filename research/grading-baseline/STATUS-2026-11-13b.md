## Protocol and rules landed today

- **Say-back scoring is one ordered instruction.** Copy test on the words (8+ word run, or the whole
  sentence with a word or two changed; if unsure it is not a copy) → idea test on the meaning →
  contradiction / literal restatement → open. The instruction ends: never use the copy test as
  evidence about the idea, and never use the idea test as evidence about copying.
- **Near-copy no longer claims ownership.** "That's still my wording" became "Say that another way,
  as you would tell a classmate." The old line asserted something the tutor cannot verify.
- **A stored key decides.** Correct when the answer states `core_idea` or any single `accept_ideas`
  entry; a word in `accept_words` counts, allowing a misspelling; the tutor does not overrule the list.
- **Unclear is bounded.** Not clear yet only for an answer that names passage content it cannot pin
  down; contentless answers are misses; one per item. A reused term earns it ("it is a short turn");
  an empty verb does not ("he did stuff with the boats").
- **Cloze:** an open cloze accepts a meaning-preserving synonym when the sentence glosses the blank;
  a defining blank wants the term (lake is not oxbow); a word that rules in what the sentence rules
  out is not a synonym (family is not household).
- **Open cloze has no word bank; banked cloze is exact.**
- **3.1.7 carve-out:** a supported effect is a key when the passage's own words carry it.
- **3.1.8 / 3.1.11:** a yes/no prompt asks why; a prompt says how many things it wants.
- **2.3.1:** the display is part of the question. Show the part that supports the intended answer, not
  a second passage that answers the same words differently.
- **Source line:** one line, `From: author, title, date`, printed once with the first passage, never
  again, and only when the attribution names an external work. Instruction 10 still walls off
  `meta`, with that single field as the documented exception.
